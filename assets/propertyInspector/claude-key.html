Shows one Claude subscription window as a circular gauge: the arc is how much of the window you've used, and the center is the time left until it resets. Reads the OAuth token Claude Code stores locally — no API key, no tokens spent. On Windows + WSL, point Credentials at the WSL file via its UNC path. Pick any fill color, or tick Auto color to color by load (green → amber → red). Minimum refresh is 180s to avoid rate limiting.
