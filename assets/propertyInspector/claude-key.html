Shows one Claude subscription window as a circular gauge: the arc is how much of the window you've used, and the center is the time left until it resets. Reads the OAuth token Claude Code stores locally — no API key, no tokens spent. Pick any fill color, or clear it to auto-color by load (green → amber → red). Minimum refresh is 180s to avoid rate limiting.
